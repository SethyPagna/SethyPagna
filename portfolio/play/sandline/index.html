SANDLINE

Tactical Arena Shooter  /  WebGL build

Ten operators, one 80 × 80 metre container yard: a two-storey centre building, six shipping-container stacks, elevated firing decks and a climbable roof. Every AI operator runs the same vision, reaction and recoil model as you — no wallhacks, no aim assist, no hitscan forgiveness: if you cannot see it, you cannot shoot it. Pick a mode on the right, then deploy.

Game mode

Pointer lock will engage — press Esc to get your cursor back. If it is refused, fallback mouse look takes over and says so on screen.
Weapon tables, arena geometry, damage falloff, hit-zone multipliers and bot behaviour parameters are shared verbatim with the Unreal Engine 5.8 project SandlineUE/ in this folder. All geometry, textures and audio in this build are generated procedurally at runtime — no external assets.
